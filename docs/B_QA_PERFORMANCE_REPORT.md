## 八、局限性

1. 无人工金标准：语义答案准确率、引用支持准确率一律不可计算（任务二暂停）。
2. 两批为整批重复运行，不是单题多次采样；未测并发/负载下的时延分布。
3. 质量指标为机械判定（引用命中/词命中/拒答一致），不能当作语义准确率。
4. 延迟测量在本机 `.venv`、本地检索路径完成，未包含进程冷启动与网络条件影响。
