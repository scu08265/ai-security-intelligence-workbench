## 5. 多跳：候选 ≠ 能力

| 项 | 事实 |
| --- | --- |
| 已构建候选题 | **31 条**（`two_hop` 10 + `cross_document` 21），证据链完整率 100%（自动校验） |
| 人工验收 | **0 条** |
| 系统真实多跳能力 | **不具备**：只有 `known_exploited` 一种关系谓词，无实体/关系抽取，无路径搜索 |
| 50 题集中的 2 道多跳题 | 系统返回了**主题相关的引用**，但**没有推理链**，判为失败 |

`two_hop` 的第二跳是"组件名出现在文档文本中"（字符串共现），
**不代表论文对该事件作出论断**；`cross_document` 只是跨文档检索。
两者都**不是**多跳推理成功。

## 9. 下一步最少需要你人工完成什么

1. 打开 `artifacts/b_eval/qa_review_worksheet.csv`（Excel 直接双击），
   在 `人工判定_答案正确性` / `人工判定_引用支持性` / `人工判定_拒答正确性` 三列填写，
   取值 `correct` / `incorrect` / `partially_correct` / `undetermined`。
2. 打开 `artifacts/b_eval/relation_review_worksheet.csv`，
   在 `人工判定` 列填写 `positive` / `negative` / `unknown` / `not_applicable`，
   并填 `人工核验人`、`人工核验时间`。
3. 关系标注完成后运行：

   ```powershell
   .\.venv\Scripts\python.exe tools\score_b_relation_annotations.py --out artifacts\b_eval\relation_score.json
   ```

   即可得到分维度与微/宏平均的 precision / recall / TP / FP / FN。
