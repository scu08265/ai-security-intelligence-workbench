## 0. 必须先读的声明

* **自动核验 ≠ 人工核验。** 本报告所有比率都是自动判定，**不得**命名为人工准确率。
* `supported` 只表示"原始快照里能找到支撑字符串，或内部逻辑自洽"，
  **不代表该关系在语义上一定成立**。
* 问答的"答案支持率"指**答案由引用原文逐字构成**，**不代表答案语义正确**。
* 语义答案准确率、关系 precision/recall/TP/FP/FN **仍然不可计算**（缺人工标签）。

## 1. 方法：与维度匹配的规则

### 1.1 关系候选

| 维度 | 规则 | 含义 |
| --- | --- | --- |
| `fixed_version` | `R-FV-PARSE` | 固定版本可解析（版本号或 `>= X` 形式） |
| | `R-FV-CONSISTENCY` | 固定版本**不得**落在受影响区间内（落在里面=自相矛盾） |
| | `R-FV-SNAPSHOT` | 该版本号出现在来源原始快照里 |
| `version_range` | `R-VR-PARSE` | 区间可解析为 PEP 440 |
| | `R-VR-SNAPSHOT` | 区间端点版本号出现在原始快照里 |
| `cvss` | `R-CV-RANGE` | score 在 0–10 |
| | `R-CV-VECTOR` | vector 以 `CVSS:` 开头且度量项 >= 6 |
| | `R-CV-SNAPSHOT` | vector 或 score 出现在原始快照里 |
| `paper_link` | `R-PL-ARXIV` | `pdf_url` 可解析出合法 arXiv 标识符 |
| | `R-PL-DOC` | 本地存在 `paper:<id>` 全文文档 |
| | `R-PL-TITLE` | 事件标题与文档首块词元重合 >= 3 |

**规则语义（重要修正）**：`…-SNAPSHOT` 规则在**未命中时记 `unavailable` 而不是 `fail`**。
原因：来源可能用结构化字段（如 OSV 的 `introduced/fixed`）表达区间，
候选值 `< 0.30.0` 是归一化推导出来的——**字符串缺失不等于关系为假**。
因此自动核验只把**逻辑自相矛盾**判为 `contradicted`。

### 1.2 问答

| 规则 | 含义 |
| --- | --- |
| `R-QA-EVIDENCE` | 答案非空且带引用或事件证据 |
| `R-QA-QUOTE` | 答案正文除模板外必须**逐字**来自被引用原文（第 4 条起只挂载、不进答案正文） |
| `R-QA-REFUSAL` | 拒答判定与 `should_refuse` 一致 |
| `R-QA-CONSISTENCY` | 不得同时出现"拒答文案"与"文档引用" |
| `R-QA-AMBIGUOUS` | 标准答案本身含糊（候选多跳题、或应作答却无任何证据可依） |

**多轮追问 / 跨文档 / 多跳三类一律保持 `auto_confidence = low`**，
并标记 `manual_review_required = true`：自动规则无法验证指代解析、跨文档综合与推理链。

| cvss | 22 | 0 | 0 |
| fixed_version | 12 | 0 | 0 |
| paper_link | 16 | 0 | 21 |

**`paper_link` 的 21 条证据不足**：`pdf_url` 指向非 arXiv 出版商
（link.springer.com / nature.com 等），本地按主机白名单**没有抓取**这些 PDF，
因此无法核对正文。**没有编造候选行**。

**`version_range` 的 37 条证据不足**：区间端点在原始快照中未逐字出现，
来源多以结构化字段表达，需人工核验。

## 5. 仍然不可计算的指标

## 6. 自动核验过程中修正的 4 个**工具**缺陷（非系统缺陷）

| # | 问题 | 影响 | 修正 |
| --- | --- | --- | --- |
| 1 | `R-VR-SNAPSHOT` 把"快照未命中"判为 `fail` | 13 条合法区间被误判为**反驳** | 未命中改记 `unavailable` |
| 2 | 结果里 `answer_head` 截断到 200 字符 | 引用核验全部失败（0/35） | 新增 `answer_full` |
| 3 | `citations_detail.quote` 截断到 160 字符 | 同上 | 保存完整 quote |
| 4 | 答案解析用 `split("\n")` | 引用原文含换行被切碎，支持率误报 1/35 | 改按 `"\n- "` 切分 |

另外把"有引用但答案走事件路径"的 11 题从引用支持率分母移出并单列
（它们是**不适用**，不是失败）。以上都是**统计工具**的修正，
**没有修改任何系统代码、数据库或共享问答流程**。

## 7. 限制

1. 自动核验只使用**本地已有**证据；未做任何联网采集。
2. `R-PL-TITLE` 的词元重合是弱证据，只用于发现明显不一致。
3. 关系 `supported` 未区分"来源直接声明"与"来源可推导"，需人工确认语义。
4. 问答自动规则无法判断答案的**语义**正确性。
5. 标准答案由任务执行者编写，**本身未经人工核验**。
